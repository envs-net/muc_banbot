# Code of Conduct

## Our Pledge

This project is part of the envs.net community ecosystem. We want participation in this project to be respectful, constructive, and welcoming.

Everyone who contributes, reports bugs, reviews changes, or participates in discussions is expected to treat others with care and respect.

## Expected Behavior

Please:

* Be respectful and patient.
* Assume good intent, but accept corrections.
* Keep discussions focused on the project.
* Give clear technical feedback without personal attacks.
* Respect maintainers' time and decisions.
* Avoid harassment, insults, hate speech, and targeted hostility.

## Unacceptable Behavior

Unacceptable behavior includes:

* Harassment, threats, or intimidation
* Personal attacks or hostile comments
* Discriminatory language or behavior
* Publishing private information without permission
* Repeated off-topic or disruptive behavior
* Abusive use of issues, pull requests, or discussions

## AI-Assisted Contributions

This project has been developed with help from ChatGPT and GitHub Copilot. AI-assisted contributions are welcome, but contributors are responsible for the code they submit.

Please review, test, and understand any AI-generated changes before opening a pull request.

## Enforcement

The project maintainer may remove, edit, or reject comments, commits, issues, pull requests, or other contributions that are not aligned with this Code of Conduct.

Repeated or serious violations may result in being blocked from participating in the project.

## Reporting

To report a Code of Conduct concern, contact the maintainer through envs.net project channels or by email if available in the repository metadata.

Please do not use public issues for sensitive interpersonal or safety reports.
